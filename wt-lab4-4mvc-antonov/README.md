## Описание
Веб-приложение на ASP.NET Core MVC (.NET 8) — каталог проката автомобилей.
Данные хранятся в памяти. Используется Bootstrap 5.

## Функциональность
- Просмотр каталога автомобилей (карточки)
- Подробная информация о выбранном авто
- Добавление нового автомобиля
- Редактирование автомобиля
- Удаление автомобиля
- Фильтр по марке
